# Student GPA Calculator in C

A simple console-based program written in C language to calculate a student's Grade Point Average (GPA) based on subject credits and obtained marks.

## Features
- Input student details (Roll Number, Name).
- Dynamic input for total subjects, marks, and subject credits.
- Automated Grade Point assignment based on marks criteria.
- Calculates total credits and overall GPA.

## Technical Concepts Used
- Basic Data Types and Variables
- Control Structures (`for` loop)
- Conditional Logic (`if-else` branching)
- Basic Mathematical Arithmetic Calculations
